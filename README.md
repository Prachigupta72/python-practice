## Getting Started

These programs are written in Python 3. They cover basic input/output, conditional logic, mathematical calculations, and loop constructs.

### Prerequisites
Make sure you have [Python 3](https://www.python.org/downloads/) installed on your machine. You can verify your installation by running:
```bash
python --version
```

## How to Run

To run any script, open your terminal/command prompt, navigate to the project directory, and use:

```bash
python <filename.py>
```

For example, to run the calculator program:
```bash
python 03_simple_calculator.py
```
